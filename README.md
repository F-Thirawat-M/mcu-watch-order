# MCU Watch Order

หน้าเว็บรวมภาพยนตร์และซีรีส์ Marvel Cinematic Universe ทุกเรื่อง สลับดูได้ 2 แบบ: เรียงตามไทม์ไลน์เนื้อเรื่อง และเรียงตามปีที่ฉาย พร้อมติ๊กเรื่องที่ดูแล้ว ใช้ได้ทั้งบนมือถือและคอมพิวเตอร์

## การใช้งาน

1. เปิดหน้าเว็บ (ไฟล์เดียว `index.html` ไม่ต้อง build) หรือ https://f-thirawat-m.github.io/mcu-watch-order/
2. กด "ดูแล้ว" ที่เรื่องที่ดูไปแล้ว แถบด้านบนจะแสดงความคืบหน้า และปุ่ม "ดูต่อ" จะพาไปเรื่องถัดไปที่ยังไม่ได้ดู
3. (ไม่บังคับ) กด "ตั้งค่า · โปสเตอร์จริง" แล้ววาง TMDB API key ของคุณเอง — ขอ key ฟรีได้ที่ [themoviedb.org](https://www.themoviedb.org/settings/api)

API key และรายการที่ดูแล้วเก็บไว้ในเบราว์เซอร์ของคุณเท่านั้น

## ฟีเจอร์

- ค้นหาชื่อเรื่อง และกรองตามประเภท (ภาพยนตร์ / ซีรีส์ / ตอนพิเศษ / มัลติเวิร์ส / ยังไม่ฉาย)
- มุมมองโปสเตอร์หรือรายการแบบกระชับ
- ซ่อนเรื่องเสริม ซ่อนเรื่องที่ดูแล้ว และข้ามไปยังยุค/ปีที่ต้องการ
- ธีมสว่าง/มืด (ตามระบบ หรือสลับเองได้)
- เรื่องที่ยังไม่ฉายคำนวณจากวันฉายอัตโนมัติ พร้อมนับถอยหลัง

## การแก้ไขข้อมูล

รายการทั้งหมดอยู่ในตัวแปร `D` ใน `index.html` แต่ละแถวคือ `[id, ชื่อ|ซีซัน, กลุ่มสี, ประเภท, วันฉาย (สหรัฐฯ), ช่วงเวลาในเรื่อง, เรื่องเสริม, หมายเหตุ]` ลำดับในอาร์เรย์คือลำดับไทม์ไลน์ อย่าเปลี่ยน `id` ของเรื่องเดิม เพราะใช้จำว่าเรื่องไหนดูแล้ว
