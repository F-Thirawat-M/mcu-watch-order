# MCU Watch Order

หน้าเว็บรวมภาพยนตร์และซีรีส์ Marvel Cinematic Universe ทุกเรื่อง สลับดูได้ 2 แบบ: เรียงตามไทม์ไลน์เนื้อเรื่อง และเรียงตามปีที่ฉาย พร้อมติ๊กเรื่องที่ดูแล้ว

## การใช้งาน

1. เปิดหน้าเว็บ
2. (ไม่บังคับ) วาง TMDB API key ของคุณเองแล้วกด "โหลดโปสเตอร์" — ขอ key ฟรีได้ที่ [themoviedb.org](https://www.themoviedb.org/settings/api)

API key และรายการที่ดูแล้วเก็บไว้ในเบราว์เซอร์ของคุณเท่านั้น
